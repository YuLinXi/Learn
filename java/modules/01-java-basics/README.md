# M01 · Java 基础与运行

前置：前端经验为用户自述，具体 Java 能力通过诊断确认。目标是从“能读部分代码”进入“能自己写类、接口和小程序”。

## 材料与深度

主教材 [R01](../../RESOURCES.md)：2.2.2、2.3、3.1.1–3.1.10、3.2.1/3.2.4/3.2.9。只补不熟的流程控制。独立实现类、构造器、访问控制、实例/静态成员、接口实现；能解释重载、重写、引用比较、拆箱、金额精度。

当前不扩展 JVM 调优、模块系统或全部新语法。选读 [UdcCtpEnumCategoryAndItemDto](/Users/yu/Desktop/work/seeyon-backends/udc-facade/src/main/java/com/seeyon/udc/common/dto/UdcCtpEnumCategoryAndItemDto.java:16)，识别字段、继承和 Lombok；暂不解释其所有父类。

## 小任务顺序

1. **A：入口诊断。** 原题唯一保存于 [PROGRESS.md](../../PROGRESS.md)。只判断比较与空值能力；不会就明确缺口，不一次发全套测试。
2. **B：运行。** 从 [练习入口](../../practice/README.md) 取得基础骨架，自己执行程序和一个测试，记录实际 Java/Maven。此时会用命令即可，M03 再解释 POM。
3. **C：对象建模。** 为 [应用字典](../../practice/DICTIONARY.md) 写 Category 类（字段、构造方法、getter）和一个校验接口及实现。先做单对象校验，不接 Spring/数据库。
4. **D：边界。** 根据明确契约判断空名称、空白、缺失 appId，解释异常为何发生；自己补一个测试。金额仅用两个小数演示 BigDecimal，销售汇总留到 M02。
5. **E：迁移。** 换一个未见过的字段规则或接口实现，由本人修改并运行。关键提示后的原题订正不替代本步。

## 本轮验收

- [ ] 能独立写类、构造器、接口实现和调用关系；解释包、访问控制、静态与实例成员。
- [ ] 能解释当前比较/空值问题，并在不同输入下判断行为。
- [ ] 本人运行小程序与正常/失败验证；区分编译错误、运行异常、断言失败。
- [ ] 完成一个未见过的小变式，记录实际帮助程度。

仅属于独立练习验收；公司 DTO 是阅读材料，不要求启动公司工程。准备工程的现成测试通过不计本模块成绩。
