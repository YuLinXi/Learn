## 小任务顺序

1. 从 [销售契约](../../practice/SALES.md) 的 S1 开始，先手工核算一组记录，再编写 Sale 与普通循环实现。
2. 用 Map 完成分组，用 BigDecimal 处理金额；将空地区映射为契约规定的分组。解释键的相等性和集合选择。
3. 用一个小泛型方法或接口消除明确的重复转换；说明类型约束。没有重复需求时只读懂公司的泛型签名，不为练习泛型制造抽象层。
4. 同一功能选择一段改为 Stream，与原期望结果对照；解释 Lambda 输入、返回值与异常传播。
5. 再从 CSV 读取数据；先保证内存数据逻辑正确，避免同时卡在 IO 与聚合。对负数量、非法金额等新输入按题目规则拒绝，保留明确错误位置。
