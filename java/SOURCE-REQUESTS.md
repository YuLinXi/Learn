## 当前缺口及影响

| 材料 | 当前状态 | 影响与处理 |
|---|---|---|
| `boot`（含 core、web/appservice/mybatis/security 等实际模块）及继承的 BOM | 用户确认暂未权限 | 公司依赖版本、BootApp/初始化、基础 DAO、框架注册和拦截顺序待核。先读可见调用，用标准机制练习；不反复要求用户提供无权限地址 |
| `cdp-report-facade`、`cdp-common` | 用户确认暂未权限 | 部分模型、公共契约和支持实现待核；按实际符号记录缺口，不把整个报表链路判为不可读 |
| `udc-starters` 中本次链路涉及的 runtime/engine 等模块 | GitLab 可见，尚未克隆；并非确认无权限 | 当前 M09 验收到设计、生成、发布调用侧及运行边界；需要追踪生成应用的真实运行请求时再补 |
| EventBus、缓存/RPC 等当前链路的具体底层实现 | 部分来自缺失基础依赖，需按符号定位 | 可以确认发送/调用和可见接收者；同步性、事务传播、重试等未证实就保持未知 |
| 公司运行环境与可解析依赖 | 尚未验证 | JDK/数据库/中间件版本、启动配置和必要服务待核；不以本地样例替代公司运行 |

只补当前学习或工作链路实际需要的源码，不要求一次获取全部公司工程。需要环境说明时记录版本、配置项名与连接关系，不在课程文档存放凭据或真实业务数据。
