# AI Agent 学习空间

从原理走到能独立开发、评测与维护 Agent 应用。主线使用 TypeScript / Node.js，中文讲解。

- [课程首页](index.html)：从浏览器进入课程。
- [完整目录](CURRICULUM.md)：14 个核心模块与 3 个进阶方向。
- [当前进度](PROGRESS.md)：续学位置、验收证据、待复习项。
- [资料索引](RESOURCES.md)：主教材与官方文档的用途。
- [学习目标](MISSION.md) · [教学方式与偏好](NOTES.md)。

## 如何继续

在这个项目里说“继续 ai-agent 学习”即可。教师先读取进度和学习记录，检查待复习项，再带你完成一个短课。也可以说“开始 M03”“复习上次内容”“今天只有 20 分钟”。

新聊天若未自动加载子目录说明，请说：“读取 ai-agent/AGENTS.md，继续学习。”

## 目录约定

| 位置 | 用途 |
|---|---|
| modules/ | 每个模块的范围、阅读入口、建议短课与验收 |
| lessons/ | 按实际学习进展生成的编号 HTML 短课 |
| reference/ | 术语与可打印速查资料 |
| assets/ | 各短课共用的样式与交互组件 |
| exercises/ | 你的练习代码、解释和验证证据 |
| learning-records/ | 有理解证据后创建，保存影响后续教学的学习记录 |

初始化准备了课程结构和一节可选短课，其余短课按进展生成。资料以官方阅读入口和章节说明整理，未下载整套教材或安装运行依赖。

## 进度如何保存

浏览器里的自测给即时反馈；页面不会自动回写文件。把答案或练习结果发回聊天后，教师根据证据更新 PROGRESS.md；达到非平凡理解时再写 learning-records。复习在续学时检查，不依赖后台提醒。
