# AI Agent 学习空间

以 TypeScript / Node.js 为主要实践语言，逐步具备独立开发、评测和维护 Agent 应用的能力，能判断何时需要 Agent，并对实现和运行结果负责。

## 学习目标

- 能解释模型、工具、运行循环、上下文、记忆、检索与工作流各自的职责。
- 能独立完成模块练习，解释实现选择，并处理指定失败场景。
- 能根据评测和执行轨迹判断改动是否有效，识别权限、可靠性和 Web 集成边界。
- 14 个核心模块分别有验收证据，经过间隔复习仍能解释和应用关键机制。

范围为 14 个核心模块与 3 个进阶选修方向，按掌握情况推进，不固定周数。中文交流，Python 以读懂教材示例为目的；实践产物以模块练习为主，当前不规划毕业项目。模型后训练等进阶方向按兴趣选择。

## 学习方式

原始资料阅读 → 阶段汇报 → 诊断 → 巩固与记录。

教师依据大纲拆分小目标，指定原文范围、阅读深度与汇报点。你自主阅读，期间随时提问；完成指定范围或遇到阻碍时回来汇报，教师据此诊断并安排下一步。有巩固价值的问题和理解变化会被筛选记录。

## 如何继续

在这个项目里说“继续学习”“汇报 M01 阶段 A”“这段原文没读懂”或“复习上次内容”即可。教师从 PROGRESS.md 恢复位置；当前任务与状态以该文件为准。

新聊天若未自动加载子目录说明，请说：“读取 ai-agent/AGENTS.md，继续学习。”

阶段汇报可按“已读范围 / 我的解释或练习 / 不确定的地方”组织。读完与理解验证分别记录；教师的讲解或演示不作为你的掌握证据。需要代码练习时，在对应模块目录内保存实现、运行方式、实际版本与验证结果。
