# A2 · 多模态、浏览器与计算机操作

[课程总览](../../CURRICULUM.md) · [进度](../../PROGRESS.md)

## 定位

核心路线之后按兴趣选修，不计入 14 个核心模块的完成率。

## 学习内容

图像与语音输入、实时交互、观察与动作空间、浏览器操作与 Computer Use。

## 对应资料

- [《深入理解 AI Agent》第 6 章](https://github.com/bojieli/ai-agent-book/blob/main/book/chapter6.md)：建立本方向的架构与设计认识。
- [Microsoft 第 15 课：Browser Use](https://github.com/microsoft/ai-agents-for-beginners/tree/main/15-browser-use)：补充浏览器操作案例。

## 建议验收

设计一个受约束的浏览器任务，说明观察、行动、确认与失败恢复。
