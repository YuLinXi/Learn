# M10 · 多 Agent 协作

[课程总览](../../CURRICULUM.md) · [进度](../../PROGRESS.md) · [资料索引](../../RESOURCES.md)

## 前置

默认完成 M09；已有基础可先通过本模块诊断再调整节奏。

## 内容与对应资料

学习内容：
- 单 Agent 与多 Agent 的选择依据。
- Manager–Worker、Handoff、Agent as Tool。
- 任务分工、上下文隔离与结果汇总。
- 共享状态、消息传递与协作终止条件。
- 多 Agent 带来的额外延迟、成本和故障传播。

主读：[OpenAI Agents SDK：Orchestration](https://openai.github.io/openai-agents-js/guides/multi-agent)。  
深入：[《深入理解 AI Agent》第 10 章：多 Agent 协作](https://github.com/bojieli/ai-agent-book/blob/main/book/chapter10.md)。  
补充：[Microsoft 第 8 课：Multi-Agent](https://github.com/microsoft/ai-agents-for-beginners/tree/main/08-multi-agent)。

## 建议阶段目标

1. 单 Agent 与协作的取舍
2. Handoff 与 Agent as Tool
3. 隔离、汇总与终止

## 模块验收

在同一小任务上比较单 Agent 和协作方式，记录输出、调用数与失败点，并给出是否值得拆分的判断。
