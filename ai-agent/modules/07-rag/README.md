# M07 · RAG 与知识检索

[课程总览](../../CURRICULUM.md) · [进度](../../PROGRESS.md) · [资料索引](../../RESOURCES.md)

## 前置

默认完成 M06；已有基础可先通过本模块诊断再调整节奏。

## 内容与对应资料

学习内容：
- 文档解析、清洗、分块与元数据。
- Embedding、向量检索、关键词检索与混合检索。
- 查询改写、重排序、上下文组装。
- 引用溯源、证据不足处理、知识更新。
- 传统 RAG 与 Agentic RAG：何时检索、如何多轮检索。
- 检索质量与回答质量的分别评估。

主读：[Hello-Agents 第 8 章](https://github.com/datawhalechina/hello-agents/tree/main/docs/chapter8)中的 RAG 部分。  
补充：[Microsoft 第 5 课：Agentic RAG](https://github.com/microsoft/ai-agents-for-beginners/tree/main/05-agentic-rag)。

## 建议阶段目标

1. 解析、分块与元数据
2. 检索、重排序和证据组装
3. Agentic RAG 与检索评测

## 模块验收

用小文档集回答带引用的问题；对证据不足的提问明确说明缺口，分别检查检索命中与回答依据。
