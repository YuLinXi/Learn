## 定位

核心路线之后按兴趣选修，不计入 14 个核心模块的完成率。

## 对应资料

- [《深入理解 AI Agent》第 8 章](https://github.com/bojieli/ai-agent-book/blob/main/book/chapter8.md)：建立本方向的架构与设计认识。

## 建议验收

针对一种失败判断应先调整上下文、工具、流程还是模型训练，并设计相应对照实验。

开始本方向时再拆短课；涉及训练的资源需求在选定实验后评估。
