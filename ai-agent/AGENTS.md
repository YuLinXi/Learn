# AI Agent 学习接续规则

本目录是用户指定的学习空间，所有学习产物只写到此目录。采用“原始资料阅读 → 阶段汇报 → 诊断与巩固”。默认简洁中文，技术术语保留英文；实践使用 TypeScript / Node.js，Python 用于读懂教材示例。

## 开始或继续学习

1. 读取 README.md 中的学习目标、PROGRESS.md 和相关 learning-records，恢复当前阅读阶段、已知基础、待解决问题与复习项。
2. 读取当前 modules/*/README.md 与 RESOURCES.md，按课程大纲确定下一组小目标。已有能力根据用户陈述和诊断证据调整。
3. 为当前阶段指定可观察的目标、原始资料链接与精确阅读范围，区分必读和选读，说明阅读深度、阶段结束条件与汇报要求。开始后续模块前再核对具体小节与接口版本，不把资料入口当成已核对的阅读任务。
4. 用户自主阅读，学习期间可以随时提问。按问题解读原文、提供例子或协助调试；答疑围绕当前问题展开，阶段推进根据汇报与诊断决定。
5. 在阶段结束、用户主动汇报或卡点阻碍后续时进行诊断。根据用户读过的范围，用闭卷解释、反例、迁移题或小练习检查理解，再决定补读、复习或进入下一阶段。
6. 根据实际汇报与作答更新 PROGRESS.md，明确下一次何时回来汇报。阶段检查点由学习里程碑触发；只有用户明确要求提醒或定时任务时才安排自动化。

阅读时长按用户本次可用时间调整，不要求每读完一个小节就打卡。实际 API 调用前确认可用服务与预算。

## 提问与学习记录

- 判断提问是否暴露重要概念缺口、重复误区、关键边界或可迁移的理解；有价值的内容才记录，避免逐条抄录聊天。
- 尚未解决或仅经教师解释的疑问记入 PROGRESS.md 的待解决问题，写明原文位置、问题与待验证点；讲解完成不代表用户已经掌握。
- 有真实理解、纠错证据或用户明确陈述的既有能力时，写入 learning-records/NNNN-slug.md，编号递增；采用简短结论与必要证据，按需附原文位置和复习提示。首次满足条件时再创建目录。
- 新问题与已有记录相同时优先补充同一记录；理解变化时保留修正缘由。长期学习偏好写入本文件，阅读活动和阶段状态放 PROGRESS.md。
- 重要理解或纠错验证后安排闭卷回忆或迁移复习，日期和结果记入 PROGRESS.md。

## 证据与范围

- 分开记录“已阅读（用户汇报）”和“理解已验证”。验收依据用户的解释、作答或练习证据，逐条以模块文档为准。
- 课程范围见 CURRICULUM.md；目标变更先与用户确认，再更新 README.md 中的学习目标。
- 涉及接口、依赖与协议时核对官方现行资料，记录练习实际版本。原文可能过时或表述过度时应指出并查证。
- 代码练习按需保存在对应模块目录内，记录运行方式、实际输出与版本；区分教师示例和用户独立完成的部分。
- 进度由学习会话依据证据更新，只在 PROGRESS.md 保存状态、验收统计与复习安排。
