# 学习前自适应复习

在 Learn 中说“继续学习”即可。AI 先检查复习状态，按本次时间安排少量复习或直接续学。你也可以说“今天只有 10 分钟”“下次周日 20 点再来”“今天跳过复习”。原学习任务始终保留；结束时说“今天先到这里”。

算法采用锁定版本的 `ts-fsrs@5.4.2` / FSRS-6，默认参数、90% 目标保持率，关闭随机扰动和分钟级短期调度。同一轮不反复刷同一知识点。回忆概率是模型估计，模块能力仍依据独立解释、迁移和实践验收。

## 续学接入流程

以下步骤由 AI 执行。命令从 Learn 根目录运行；也可在 `ai-agent/` 中将 `--prefix ai-agent/review` 改为 `--prefix review`。JSON 请求文件由文件工具写入 `review/request-<会话唯一ID>.json`，命令的 `--input` 传该文件名（相对 `review/`）或绝对路径；同一会话顺序复用、跨会话各用不同文件，避免覆盖请求。下文的 `request.json` 是文件名占位，执行时替换为本会话文件名。题目和作答通过文件传递。

1. **恢复上下文**：读取 `PROGRESS.md`、相关学习记录、当前模块和本文件。新产生且已有真实作答证据的知识点，按下文 `register` 登记；已有项目启动时已登记。根据下一步学习内容选择已登记的直接前置知识点 ID；没有依据时使用空数组。只选用户已学的范围，未知部分继续作为原课程任务。
2. **开始或恢复**：运行 `npm --prefix ai-agent/review run review -- start`。已知时间、前置关系或下次计划时，用文件工具创建以下请求，再加 `--input request.json`；未提供的字段省略，不先追问。下次计划时间由用户提供，按上海时区解析为明确未来时间；只有日期或大致时段、无法确定具体时间时先省略 `nextSessionAt`，实际回来时按真实时间重算。

   ```json
   {
     "module": "M01",
     "availableMinutes": 20,
     "prerequisiteIds": ["m01-bigram-context"],
     "nextSessionAt": "2026-10-25T20:00:00+08:00"
   }
   ```

   工具可从进度中推断当前模块；时间和前置知识由 AI 从本次用户输入及模块内容补充。`resume-review` 时逐字恢复 `pending.prompt`，保留已给过的提示；`continue` 时接回原学习任务；`review` 时只从 `selected` 中选一道题。候选不是强制待办，`remainingCount` 不要求本次清空。
3. **保存题目后展示**：写请求 `{ "topicId": "实际ID", "prompt": "完整题目、语料和条件", "rubric": "本题所检验的知识点、正确依据与边界" }`，执行 `ask --input request.json`。用返回的 `result.id` 作为本题 `attemptId`，再向用户展示题目；判分依据留待作答后讨论。开场维持“位置／本次只做／完成标志”，说明复习原因和预计时间。出现待校准项时如实说明，保持率不当作测得的个人记忆成绩。
4. **答题与提示**：用户先独立作答，按同一知识点、相近难度的新情境检查保持，避免用尚未学过的复杂内容判定遗忘。需要提示或揭示答案前，先执行 `hint`，保存提示全文及已有原回答。不确定是否答对时先核实，不提交评分。暂停时保留待答题，既有学习断点继续留在 `PROGRESS.md`。
5. **保存结果**：执行 `answer --input request.json` 保存原回答、是否正确、是否依赖帮助和反馈。工具返回 `saved: true`、`summarySynced: true` 才能宣称存档完成；读回 `state.json` 的对应事件及 `PROGRESS.md` 复习段确认一致。有价值的理解变化再按主规则补充学习记录，模块状态由学习证据另行决定。
6. **结束开场复习**：再次执行只读 `plan`，有合适预算才继续下一道题；没有则执行 `finish`，恢复 `PROGRESS.md` 当前的原学习断点。用户明确“跳过复习”或指定直接进行的学习任务时，执行 `start` 后 `skip`，按当前进度和用户选择直接续学，算法评分和日期保持原样。用户结束整次学习时，保留未答复习题并执行主规则的存档；下一次仍恢复原题。

同一天的重复“继续”沿用本轮预算和跳过选择；隔天重新计算。用户明确要求额外复习时，`start` 输入可加 `"force": true`。有未答复习题时始终先恢复它，用户明确跳过才清除。若原学习任务已在其他聊天推进，恢复时以最新 `PROGRESS.md` 为准，`resumeTask` 是开始复习时的备用快照。

## 作答请求与评分

提示请求示例（`hint --input request.json`）：

```json
{
  "attemptId": "ask 返回的 id",
  "text": "实际准备给出的提示",
  "answerBeforeHint": "用户在提示前的原回答，没有则省略此字段"
}
```

作答请求示例（`answer --input request.json`）：

```json
{
  "attemptId": "ask 返回的 id",
  "answer": "用户实际回答全文",
  "correct": true,
  "assisted": false,
  "effort": "normal",
  "feedback": "判定依据、达到的范围和仍未验证的边界"
}
```

| 实际表现 | 评分 |
|---|---|
| 未正确回忆，或依赖提示/已看答案才完成 | Again |
| 独立正确，但明确费力回忆 | Hard |
| 独立正确，无明确吃力或特别熟练证据 | Good（`effort: normal`） |
| 独立正确，且有明确熟练回忆证据 | Easy |

已保存提示时，工具强制按依赖帮助处理，即使请求错误地传了 `assisted: false`。`Hard` 只用于独立正确。没有作答、只有教师讲解或用户跳过，都不调用 `answer`。不要根据聊天等待时长推断吃力程度；未提供实际耗时则按知识点预计分钟数计入预算，并标注为估计。重复提交同一 `attemptId` 和同一内容不会重复计分，冲突内容会报错。

## 候选选择与状态

- 默认开场预算 5 分钟；给出本次时间时取其四分之一，最多 5 分钟。一次一道题，以 `plan` 返回的预算为准；时间不够就直接续学。到期项按直接前置关系、当前模块、FSRS 到期状态、预计回忆概率及历史证据日期排序。
- 历史证据只有日期、没有 FSRS 评分的知识点标为待校准，最早次日成为候选，回忆概率保持空值。首次真实作答才生成模型状态。旧计划日期仅作来源说明。
- 已提供下次计划时间时，已学前置知识若届时预计低于目标，可在本次考虑检查；同一天刚做过的未到期项不因此重复。未来计划本身不更新到期日或伪造复习。
- `state.json` 保存算法状态、原题、提示、原回答、反馈和开场回合；`PROGRESS.md` 保存课程状态和原学习任务，其“复习队列”是工具生成的摘要。AI 更新进度时保留生成段，修改其他学习字段后可执行 `sync` 刷新摘要。原题、原回答及评分以 JSON 中的真实事件为准。
- 所有写入加锁、通过临时文件原子替换并读回；若 JSON 已保存而摘要失败，工具会明确报出，运行 `sync` 恢复。异常退出留下锁时，确认没有正在写入的进程后再移除 `state.json.lock`。状态损坏时保留文件并报告，不重置历史。
- 本工具由学习会话触发，随项目文件恢复。记忆曲线用默认参数启动，尚未用你的个人历史训练；没有后台提醒或额外模型 API 请求。

## 登记新知识点

仅登记已有真实学习证据的独立知识点，标题和范围应能用一道短题检查；将未学、待讲解的内容保留在课程任务中。先按主规则保存学习记录，再执行 `register --input request.json`：

```json
{
  "topics": [{
    "id": "m02-agent-loop",
    "title": "模型、工具与应用在 Agent 循环中的职责",
    "module": "M02",
    "source": "learning-records/实际存在的记录.md",
    "lastEvidenceDate": "实际作答日期 YYYY-MM-DD",
    "priorSummary": "真实结果及尚未验证的边界",
    "minutes": 2
  }]
}
```

`source` 必须是 `ai-agent/` 内实际存在的 Markdown 文件。重复登记同一 ID 不重置已有模型；继续学习时实际复习结果走 `ask` / `answer` 流程。登记不是新增一次通过或复习。

## 安装与验证

首次已安装。换设备后在 Learn 根目录执行 `npm --prefix ai-agent/review ci`，需要 Node.js 22+。正常学习只需聊天，命令由 AI 执行。

```sh
npm --prefix ai-agent/review run review -- plan
npm --prefix ai-agent/review run typecheck
npm --prefix ai-agent/review test
```

`plan` 只读，不开始学习也不产生评分。测试全部使用临时目录和固定时间；`--root` / `--now` 仅供隔离验证，真实学习使用默认项目目录和当前时间。源项目：[ts-fsrs v5.4.2](https://github.com/open-spaced-repetition/ts-fsrs/tree/v5.4.2)。
