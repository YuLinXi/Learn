# Mission: AI Agent 原理、开发与工程化

## Why

以 TypeScript / Node.js 为主要实践语言，逐步具备独立开发、评测和维护 Agent 应用的能力，使自己能判断何时需要 Agent，并对实现和运行结果负责。用户已于 2026-10-16 明确确认沿用这一目标。

## Success looks like

- 能解释模型、工具、运行循环、上下文、记忆、检索与工作流各自的职责。
- 能完成模块内的小练习，独立解释实现选择，并处理指定失败场景。
- 能根据评测和执行轨迹判断改动是否有效，识别权限、可靠性和 Web 集成边界。
- 14 个核心模块分别有验收证据，经过间隔复习仍能解释和应用关键机制。

## Constraints

- 按 14 个核心模块 + 3 个选修方向推进，不固定周数。
- 中文教学；TypeScript / Node.js 实践；Python 以读懂主教材示例为目的。
- 每次学习时长、现有能力和 API 预算尚未确认；开课时按需要了解。
- 进度保存在本学习空间，依据作答与练习更新。

## Out of scope

- 当前不规划毕业项目，不强制重复学习多套入门课程。
- 模型后训练等进阶方向不作为核心路线完成的条件。
