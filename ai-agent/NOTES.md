## 开课时了解

- TypeScript / Node.js、异步编程、JSON Schema 的实际熟悉程度。
- 是否调用过 LLM API；哪些 Agent 概念已能独立解释。
- 本次可用时长；涉及 API 练习时再明确可用服务与预算。

原路线按 TS / Node.js 开发者设计，这不等于用户的能力已经验证。先诊断，再选择难度。

## 每次教学

1. 从 PROGRESS.md 恢复位置，结合已有学习记录选题；先完成到期回忆。
2. 一次短课只追求一个可观察的能力。默认 10–20 分钟，可按本次时间缩短。
3. 用中文解释最少必要知识，推荐一份主要原始资料。
4. 让用户先作答或动手，再给提示和反馈；需要示范时明确标注。
5. 记录结果、困难和下一步；理解证据达到要求后写学习记录并安排复习。

页面自测供即时反馈，不自动写入学习状态；用户发回结果后再更新文件。续学时检查复习队列，当前没有定时通知任务。
